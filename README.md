# Netflix Media Dataset - EDA

## Project Overview

This project performs Exploratory Data Analysis (EDA) on the Netflix Media Dataset.

The main objective of this project is to analyze Netflix content and identify useful patterns and insights related to movies and TV shows.

## Objectives

- Understand the structure of the Netflix dataset
- Clean and preprocess the data
- Handle missing values and duplicate records
- Analyze Movies vs TV Shows
- Explore content distribution by country
- Analyze ratings and release years
- Identify popular genres and content trends
- Visualize important patterns using charts

## Dataset

The dataset contains information about Netflix titles such as:

- Show ID
- Type
- Title
- Director
- Cast
- Country
- Date Added
- Release Year
- Rating
- Duration
- Listed In
- Description

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Files

- `netflix_eda.ipynb` – Complete Exploratory Data Analysis
- `netflix_titles.csv` – Original Netflix dataset
- `cleaned_netflix_data.csv` – Cleaned dataset after preprocessing

## Data Cleaning

The project includes:

- Handling missing values
- Removing duplicate records
- Converting columns into appropriate data types
- Cleaning text and categorical data
- Preparing the dataset for analysis

## Exploratory Data Analysis

The analysis includes:

- Distribution of Movies and TV Shows
- Content released over the years
- Top countries producing Netflix content
- Popular genres
- Rating distribution
- Movie duration analysis
- Year-wise content trends

## Key Insights

The visualizations help understand how Netflix's content library has evolved over time and provide insights into the types, ratings, genres, and countries associated with Netflix content.

## Conclusion

This project demonstrates the complete process of performing Exploratory Data Analysis using Python. The cleaned dataset and visualizations make it easier to understand patterns and trends in Netflix's content library.
